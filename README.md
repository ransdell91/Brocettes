# Brocettes — Campaign Companion

A player-facing companion for our D&D campaign: searchable characters, NPCs,
quests, lore and session recaps, built from the session transcripts our bot
records and fed in automatically each week from the bot's Google Doc.

- [`docs/data-model.md`](docs/data-model.md) — what we track and why
- [`docs/ingestion.md`](docs/ingestion.md) — how the weekly Google Doc import works
